> 먼저 원래 맥에서 **ver14.9 커밋·Push**까지 해 두어야 다른 컴퓨터에서 받을 수 있어요.

## 1. 다른 컴퓨터에서 시작하는 순서

1. **언리얼 5.4 설치**: Epic Games 런처에서 설치해요.
2. **저장소 받기**: GitHub Desktop으로 `home-exhibition`을 아무 데나 clone해요. zip을 꺼내려고 받는 거라 이 사본은 임시예요.
3. **언리얼 프로젝트 풀기**: `transfer/unreal_project_1120.zip`을 원하는 곳에 풀어요. 그러면 `AICLASS_prototype1/` 폴더가 생겨요.
4. **저장소를 그 폴더 안에 다시 clone**: 결과가 `AICLASS_prototype1/home-exhibition/`이 되게 해요. `시연시작.command`가 한 칸 위 폴더에서 언리얼 프로젝트를 찾기 때문에 이 위치가 꼭 필요해요. 2번에서 받은 사본은 지워도 돼요.
5. **설정 복사**: `transfer/config.json`을 `interaction/config.json`으로 복사해요.
6. **Python 패키지 설치**: 맥 터미널에서 한 줄씩 입력해요.

   ```
   cd 경로/AICLASS_prototype1/home-exhibition/interaction
   ```
   ```
   pip3 install --default-timeout=200 --retries 10 -r requirements.txt
   ```
   ```
   pip3 install pygame
   ```
   ```
   pip3 install --default-timeout=200 --retries 10 -r requirements_yolo.txt
   ```
   마지막 줄(YOLO)은 카메라 시연 때만 필요해요. YOLO 모델 파일은 첫 실행 때 자동으로 받아요.
7. **언리얼에서 `AICLASS_prototype1.uproject` 열기**: L_Current가 뜨는지 확인해요. 처음 열 때는 셰이더 컴파일 때문에 오래 걸려요.
8. **시연**: Finder에서 `home-exhibition/시연시작.command`를 두 번 클릭해요.

**Claude랑 이어 하려면**: 새 컴퓨터의 `AICLASS_prototype1` 폴더를 연결하고 "인수인계 파일 보고 이어 하자"라고 하면 돼요. `HANDOFF.md` 맨 앞에 다른 컴퓨터용 안내가 있어요.

**주의**
- 맥 기준이에요. 윈도우에서는 시험해 보지 않았어요.
- 화면 분할은 1920×1080에서만 확인했어요. 다른 해상도면 `config.json`의 `unreal_game.layout:"manual"` + `res`/`pos`로 맞춰요.
- zip은 11/20 상태를 찍어 둔 사본이에요. 원래 맥에서 언리얼을 또 고치면 zip을 새로 만들어 커밋해야 해요.

### 팀이 정할 것
1. 스탠드 켜는 방법: 스마트 플러그 / USB 릴레이 / 아두이노 릴레이
2. 브라운관 출력: 언리얼 TV 화면만 따로 내보내기 / 맥 영상 플레이어를 신호로 제어
3. 앉음 판단: 카메라만 / 소파 압력 센서 추가
4. 지하철 칸이 가려지면: 카메라 2대 / 입장하면 지하철 칸에 있는 걸로 보기
5. **지하철 칸과 집 사이 문**
   - 실물 문을 어떻게 만들지: 여닫이 문 + 도어클로저(지금 설계: 폭 80, 집 쪽으로 열림) / 커튼·발 같은 가벼운 문 / 문틀만
   - 문이 열린 걸 어떻게 알아챌지: 지금은 '집 구역에 0.4초 들어오면 문 지남'으로 봄 → 그대로 카메라로 / 문에 센서(자석 리드 스위치 등)를 달아 실제로 열릴 때 신호
   - 문 열림이 무엇을 일으킬지: 지금은 지하철 소리 2초에 잦아듦만. 기획 의도 페이지의 '문 열면 불·TV·CCTV 녹화 시작'과 맞출지
   - 문이 카메라 시야를 가리지 않는지, 열린 문이 관객 동선·소파 쪽을 막지 않는지
6. 손잡이·안내방송을 넣을지, TV 채널에 무슨 영상을 넣을지
7. 기말 전시 날짜·장소·운영 인원
