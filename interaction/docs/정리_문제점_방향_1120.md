# Home Sweet Home 인터랙션 — 작업 정리 · 문제점 · 발전 방향 (2026-11-20)

원본(그림 포함): Claude 문서 "Home Sweet Home 인터랙션 — 작업 정리 · 문제점 · 발전 방향" (정지원 계정). 이 파일은 다른 컴퓨터에서 보기 위한 글 사본.

## 한눈에
**'가상으로 한 바퀴'는 끝났고, '실제 방에서 한 바퀴'는 아직이에요.**
- 된 것: 입장 → 지하철 소리 → 문 → TV·조명·담요·리모컨 반응 → 소리 세 갈래가 커짐 → 퇴장 QR. 전부 언리얼 안(가상 공간)에서 확인.
- 안 된 것: 실제 방의 장치 출력(스탠드, 브라운관에 TV 영상만, 출구 QR 화면, 스피커 배치), 실제 카메라로 앉기·바라보기·담요·리모컨 인식, 진짜 소리와 TV 영상.
- 가장 큰 위험: 작품 핵심('편안 → 불편')을 소리가 전부 맡는데 아직 임시 합성음.
- 마감: 크브페 지원서 11/23(월) 23:59. 기말 전시 날짜 확인 필요.

## 발전 방향 (로드맵)
1. **보여줄 것 맞추기 (~11/23)** — 지원서·홈페이지 설명을 지금 동작으로, 게임식 시연 직접 해 보고 기록 영상 확보, 서지오에게 소리 사양 전달 → 관문: 크브페 지원서 제출
2. **실제 방으로 (다음 주)** — 언리얼 → 실제 장치, 카메라 자리·가벽 사각 확인, 마커 인쇄·앉기·바라보기 실물 시험 → 관문: 사람이 들어가 조명·TV·소리·QR이 실제로 반응
3. **진짜 내용 넣기** — 서지오 소리 교체·겹침 튜닝, TV 채널 영상 확정(PL_TV만 교체), 감지가 빠져도 시간으로 소리가 커지는 안전장치 → 관문: 팀 밖 사람이 '불편해져서 나갔다'고 말함
4. **전시 운영 준비** — 한 명씩 줄 규칙·안내문, 하루 내내 켜 두기 시험, 1분 재시작 절차 → 관문: 전시 오픈

원칙: ① 판단은 계속 언리얼 블루프린트가, 실행은 실제 장치가 (블루프린트가 신호를 내보내고 작은 중계 프로그램이 스마트 플러그·영상 플레이어를 움직임) ② 카메라 혼자 다 하지 않기 (필요하면 소파 압력 센서) ③ 감지가 틀려도 체험의 뼈대는 유지 ④ 게임식 시연은 백업 모드이자 발표 자료로 유지.

## 팀이 정할 것
1. 스탠드 켜는 방법: 스마트 플러그 / USB 릴레이 / 아두이노 릴레이
2. 브라운관 출력: 언리얼 TV 화면만 따로 / 맥 영상 플레이어를 신호로 제어
3. 앉음 판단: 카메라만 / 소파 압력 센서 추가
4. 지하철 칸이 가려지면: 카메라 2대 / 입장하면 지하철 칸으로 간주
5. 지하철 칸과 집 사이 문: 실물 문 종류(여닫이+도어클로저 / 커튼 등), 열림 감지(지금처럼 카메라 집 구역 진입 / 문 센서), 문 열림이 일으킬 반응(지금은 지하철 소리 잦아듦만), 카메라 시야·동선을 가리지 않는지
6. 손잡이·안내방송 최종 여부, TV 채널 내용
7. 기말 전시 날짜·장소·운영 인원
