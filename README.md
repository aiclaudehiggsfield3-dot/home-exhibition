# Home Sweet Home — 인터랙티브 전시 'home'

AI 기반 영상 제작 워크샵 기말 프로젝트 / 크리에이티브 브릿지 페스티벌 지원작.

- `index.html`: 첫 화면 — 페이지 목록(01~06) + 받기
- `intent.html` 01 기획 의도 · `space.html` 02 공간 소개 · `furniture.html` 03 가구 정리 · `decisions.html` 04 확정된 내용 · `experience.html` 05 직접 체험 · `tech.html` 06 인터랙션·장비
- `assets/site.css`: 모든 페이지 공통 디자인
- `experience.html`: 직접 체험해 보기 — 본안 치수 웹 3D + 천장 CCTV 작동 화면 (three.js는 `assets/vendor/`에 포함, 소리·영상은 임시)
- `reports/result_sample.html`: QR을 찍으면 보이는 결과 화면 예시
- `assets/final_*.jpg`: 본안(L_Opt5B) 최종 작품 사진, `downloads/`: 크브페 사진 묶음
- `scripts/`: Unreal 레벨·렌더 생성 스크립트
- `archive/`: 지난 기획(배치안 1~5, 프로젝터안, 리클라이너안, 이전 인터랙션 설계)과 전체 진행 기록 — 참고용, 현재 설계 아님
